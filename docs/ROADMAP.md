# Roadmap

## v0.1（当前）

- 标题到结构化 ContentPlan；
- Brand DNA 与版本指纹；
- Mock / Manual / OpenAI 图片 Provider；
- 本地与可选多模态视觉审查；
- 1080×1440 确定性中文排版；
- 项目历史、参考图、ZIP 导出；
- FastAPI 网页工作台与 CLI；
- 合规关键词提示与 CI 测试。

## v0.2

- 网页端可视化编辑 ContentPlan 和 VisualBrief；
- 单页重生成，而不是整组重跑；
- 多套品牌主题与栏目模板；
- 参考图联系表和淘汰机制；
- C2PA/元数据标识能力调研与可选写入；
- 发布数据手工回填与选题表现分析。

## v0.3

- 独立事实资料库与来源摘录；
- 可配置的内容评价集（准确、原创、收藏价值、品牌一致）；
- A/B 封面生成与受控实验；
- 模型成本、耗时和失败率仪表盘；
- 在明确授权和平台接口允许的前提下增加发布辅助，而不是无人审核自动群发。
